ANÁLISE DOS CASOS LIMITES:
1) Para R3 = 0 Ohm:
   - Denominador = (R1*R2)*C = 125.0
   - Numerador de b = mu*R3 = 0  ==>  b = 0
   - Numerador de a = (1 - mu)*R1
   - Conclusão Física: A entrada u(t) fica desacoplada da saída y(t).
     A saída permanece em y(t) = 0 para qualquer entrada u(t).

2) Para R3 -> infinito (R3 aberto):
   - a = 1 / ((R1 + R2)*C) = 1 / (60 * 0.25) = 1 / 15 s = 0.06667 rad/s
   - tau = (R1 + R2)*C = 15.0 s
   - b = mu / ((R1 + R2)*C)
   - K = mu (Ganho estático é exatamente igual a mu)
   - Conclusão Física: Circuito RC passivo série convencional com ganho estático mu.
